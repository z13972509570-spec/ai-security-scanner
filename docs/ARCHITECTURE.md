## 核心模块

### 1. Scanner (scanner.py)
- 协调扫描流程
- 文件遍历
- 结果聚合

### 2. Python Scanner (scanner/python_scanner.py)
- AST 静态分析
- Python 特定漏洞检测

### 3. JavaScript Scanner (scanner/js_scanner.py)
- 正则模式匹配
- JS 特定漏洞检测

### 4. Reporters
- CLI: 彩色终端输出
- HTML: 交互式报告
- JSON: 机器可读格式

### 5. AI Fix Engine (ai_fix.py)
- 基于 LLM 的自动修复建议

         │

└────────┬────────┘
         │
         ▼

         ▼
